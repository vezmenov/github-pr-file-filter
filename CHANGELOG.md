# Changelog

## 1.1.0

- 22 selectable test naming and directory presets across language ecosystems.
- Custom extension suffixes, path globs and always-show exceptions.
- Independent tree and diff filtering, with a master switch.
- Settings page and toolbar popup, path preview, JSON import/export and English/Russian UI.
- MIT license, public development documentation and CI.

## 1.0.1

- Hide complete test diff cards and progressive wrappers as well as tree entries.
- Preserve native filters, Viewed state, comments, review drafts and keyboard focus.

## 1.0.0

- Initial local test-file tree filter integrated into GitHub's native file menu.
