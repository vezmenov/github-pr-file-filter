# GitHub PR File Filter — фильтр файлов GitHub PR

[Chrome Web Store](https://chromewebstore.google.com/detail/github-pr-file-filter/femlegodeikdcchheikbcdnpcckdpbic) · [English](../README.md) · [Релизы](https://github.com/vezmenov/github-pr-file-filter/releases) · [Сообщить об ошибке](https://github.com/vezmenov/github-pr-file-filter/issues)

Расширение скрывает тестовые файлы и выбранные типы файлов в дереве GitHub PR и в карточках diff справа. Скрываются целые карточки, включая свёрнутые и загруженные позже. Выключение фильтра возвращает файлы; Viewed, комментарии и черновики ревью не меняются.

## Установка

1. Откройте [GitHub PR File Filter в Chrome Web Store](https://chromewebstore.google.com/detail/github-pr-file-filter/femlegodeikdcchheikbcdnpcckdpbic).
2. Нажмите **Установить / Add to Chrome** и подтвердите установку.
3. Перезагрузите страницу GitHub PR, откройте меню рядом с **Filter files…** и включите **Скрыть тесты**.

Публичная доступность версии **1.1.0** в магазине подтверждена 18 октября 2026 года (Europe/Moscow).

### Альтернатива: установка распакованного релиза

1. Скачайте `github-pr-file-filter-<версия>.zip` из [релизов](https://github.com/vezmenov/github-pr-file-filter/releases) и распакуйте.
2. Откройте `chrome://extensions` или `edge://extensions`, включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите каталог с `manifest.json`. При установке из исходников выберите `extension/`.
4. Перезагрузите страницу PR, откройте меню рядом с **Filter files…** и включите **Скрыть тесты**.

При обновлении замените файлы, нажмите **Перезагрузить** на карточке расширения и перезагрузите PR. Материалы Chrome Web Store и статус публикации с датой находятся в [инструкции](CHROME_WEB_STORE.md).

## Настройки

Откройте **Настройки** через popup расширения или меню фильтрации GitHub. Настройки хранятся локально в профиле браузера и применяются в других открытых вкладках GitHub. Автоматическое скрытие тестов изначально выключено.

| Настройка | Действие |
| --- | --- |
| Включить фильтрацию | Общий переключатель. Выключение возвращает всё, что скрыло расширение. |
| Скрыть тесты | Включает выбранные пресеты распознавания тестов. |
| Дерево / Diff | Определяет панели, в которых скрываются файлы. |
| Пресеты тестов | Позволяют отключить отдельные соглашения об именах и каталогах. |
| Скрываемые расширения | Суффиксы `.snap`, `.map`, `.d.ts`, `.min.js` и другие. Работают и при выключенном скрытии тестов. |
| Скрываемые пути | Пользовательские glob-маски. Работают и при выключенном скрытии тестов. |
| Всегда показывать | Исключения, которые имеют приоритет над пресетами и скрывающими правилами. |
| Учитывать регистр | Различать или игнорировать заглавные и строчные буквы в путях. |
| Язык | Автоматически по браузеру, русский или английский. |

Введите по одному расширению или правилу на строку. Проверка пути показывает результат до сохранения. Настройки можно экспортировать в JSON и импортировать в другом профиле. Импорт и сброс меняют форму; для применения нажмите **Сохранить**. Формат экспорта: `{ "version": 1, "hideTests": false, "settings": { ... } }`. Импорт проверяется перед применением; облачной синхронизации нет.

### Маски

Путь считается относительно корня репозитория. Маска без `/` сопоставляется с именем файла на любой глубине. `*` — символы внутри одного сегмента, `**` — включая каталоги, `?` — один символ. `**/` допускает отсутствие каталогов. Маска должна совпасть с целым путём или именем, а не с его подстрокой.

| Маска | Что скрывает |
| --- | --- |
| `*.snap` | Snapshot-файлы в любых каталогах. |
| `**/*.generated.ts` | Сгенерированные TypeScript-файлы. |
| `packages/legacy/**` | Все файлы в `packages/legacy/`. |
| `**/fixtures/**` | Файлы в любом каталоге `fixtures`. |
| `src/config?.json` | Например, `src/config1.json` и `src/configA.json`. |

Пример: скройте расширения `.snap`, `.map` и маску `**/*.generated.ts`, затем добавьте `tests/README.md` в **Всегда показывать**. Этот файл останется видимым для расширения; встроенные фильтры GitHub продолжают действовать.

Регулярные выражения, скобки `[]`, фигурные скобки `{}`, начальный `!` и обратный слеш не поддерживаются. Используйте отдельные маски и `/`; исключения задаются отдельным списком. В каждом списке до 200 масок по 300 символов; в списке расширений до 100 суффиксов по 40 символов, включая точку. Суффикс можно ввести как `snap` или `.snap`.

## Распознавание тестов

22 пресета покрывают распространённые соглашения JavaScript/TypeScript, Playwright/Cypress, Python, Go, Ruby, JVM, .NET, PHP, Rust, Dart/Flutter, Swift, C/C++, Elixir/Erlang, shell, R, Julia, Lua, Clojure, Haskell, Perl и Zig. В настройках приведены примеры каждого пресета. Общий пресет скрывает тестовые каталоги вместе с их вспомогательными файлами и ресурсами, а также Cucumber-файлы `.feature`.

Пресеты могут пересекаться. Отключение языкового пресета не возвращает файл, если срабатывает другой выбранный пресет: например, `.spec.ts` внутри `tests/`. Отключите соответствующий пресет каталогов или добавьте маску в **Всегда показывать**.

Расширение проверяет имена и пути, не содержимое файлов. Нестандартные соглашения задаются масками. Тесты внутри обычного production-файла нельзя определить по его имени. Полное распознавание всех фреймворков и всех структур репозитория не гарантируется. JVM-пресет учитывает тестовые каталоги: `src/main/java/ConnectionTest.java` остаётся видимым.

Развёрнутые папки, содержащие только скрытые файлы, тоже скрываются. Свёрнутые сохраняются: GitHub может ещё не отрисовать их содержимое. Поддерживаются страницы GitHub PR `/files` и `/changes`. Если встроенное меню не найдено, переключатель появляется рядом с поиском файлов. GitHub Enterprise и другие хостинги кода не поддерживаются.

## Приватность

Единственное API-разрешение — `storage` для локальных настроек. Content script ограничен `https://github.com/*`, чтобы переживать переходы внутри GitHub; фильтр работает только в просмотре файлов PR. Расширение локально обрабатывает содержимое сайта: отображённые имена файлов, пути относительно репозитория и метаданные DOM. Путь текущего URL проверяется для включения фильтра. Пути, извлечённые со страницы, не сохраняются и не передаются; введённые вами маски хранятся как локальные настройки. Расширение не отправляет запросы, не собирает аналитику или историю посещений, не загружает удалённый код и не использует учётные данные. [Политика приватности](PRIVACY.md).

## Разработка

Нужны Node.js 26, npm и системная команда `zip` для упаковки. У установленного расширения нет npm-зависимостей.

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm run package
```

Unit/DOM-тесты проверяют правила и работу с разметкой. Browser smoke загружает настоящий Manifest V3 в отдельный временный профиль Chromium и проверяет контролируемую страницу, сохранение настроек, обмен между вкладками и переходы. Эта проверка не использует пользовательский профиль и не подтверждает совместимость с любыми будущими изменениями GitHub.

Упаковка создаёт `dist/github-pr-file-filter-<версия>.zip` только из файлов `extension/`, с `manifest.json` в корне. CI выполняет те же проверки и сохраняет ZIP как артефакт.
